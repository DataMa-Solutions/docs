* **PowerPoint**: keep your Datama analyses interactive inside slides with the free **HTML viewer by Datama** Office add-in:
  * Install from the PowerPoint marketplace (search for **HTML viewer by Datama** or **Datama**)
  * Export HTML from another Datama extension (**Download as HTML**)—available on all hosts except Power BI
  * Import via **File upload** or **Custom code**
  * Stay interactive in edit mode and in presentation / slideshow mode (dataset fixed at export time)
  * Supports Compare, Detect, Assess, and Explore
  * Completely free—complements your existing Datama extensions

See the documentation: [Datama in PowerPoint]({{site.url}}/{{site.baseurl}}/extensions/how-to-use/powerpoint.html)
