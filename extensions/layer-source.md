# Purpose

**Layer Source** shows the data that feeds the visual, without leaving the chart. Use it to check what Datama receives from your report (columns, values, filters applied), and — where the data is embedded in the visual — to fix or update it on the spot.

Open it with the **See Source** button in the header, just left of **Save**.

<br/>

# Where it is available

| Host | Button | Data |
|:---|:---|:---|
| **PowerPoint** | Yes | **Editable** |
| **HTML export** | Yes | **Editable** |
| **Datama AI skill** (Claude, Cursor…) | Yes | **Editable** |
| **Power BI, Tableau, Looker Studio, Qlik** | Yes | Read-only — the data comes from your BI report; change it there |
| **Google Sheets™, Excel** | No | The data is already in your sheet |

The icon tells you which mode you are in: a **source** icon when the data is editable, a **database** icon when it is read-only.

<br/>

# Read the data

| Mode | Shows |
|:---|:---|
| **Sample** | The rows of the dataset, as received |
| **Unique** | The distinct values of each column, side by side — handy to spot a typo or an unexpected segment |

The toolbar shows the number of rows and columns and the dataset creation date. **Search** and **column sort** apply to the whole dataset; **Show the first** sets how many rows are displayed.

<br/>

# Edit the data (PowerPoint, HTML export, AI skill)

* **Double-click** a cell to edit it.
* **Paste** a block copied from Excel or Google Sheets™ while a cell is in edit mode: it fills right and down from that cell. Extra columns beyond the dataset are ignored (a warning tells you).
* Close the panel: the analysis recomputes with the new data.
* Click **Save** to keep the edited data with the visual. Without Save, reloading the page brings back the original data.

Typical uses: refresh a PowerPoint slide with this month's figures, correct a label before a meeting, or adjust a dataset generated by the AI skill — without going back to the source.
