# 1. Introduction

Thank you for choosing **HTML viewer by Datama** for PowerPoint, developed by Datama (7 rue Pierre Ginier, 75018 Paris). Datama is committed to protecting the confidentiality and security of user data. This Privacy Policy explains how data is handled when using the HTML viewer by Datama PowerPoint Add-in service.

# 2. PowerPoint Add-in Privacy Policy

## 2.0. Scope of This Policy
This policy applies to the HTML viewer by Datama PowerPoint Add-in service and related processing activities. It covers the display of Datama HTML exports (Compare, Detect, Assess, Explore) as well as generic custom HTML loaded by the user. It does not describe the privacy practices of the Datama marketing website.

## 2.1. Information Collection
HTML viewer by Datama for PowerPoint does not sell or monetize your presentation content. The add-in only processes the data needed to display interactive HTML content inside PowerPoint.

When you upload an HTML file or paste HTML via **Custom code**, that content (including any dataset and configuration embedded in a Datama export) is processed locally in the add-in runtime to render the visualization. The loaded HTML and related display settings are stored in Office document settings associated with your presentation so the content can be restored when you reopen the file.

When personal information is involved (for example, account identifiers, business contact details, support exchanges, or billing/admin metadata related to other Datama products), Datama processes it only for service delivery, support, security, and legal compliance.

## 2.2. User Consent
By installing and using the add-in, users and administrators accept the data practices described in this policy and in Microsoft 365 add-in governance settings.

## 2.3. Data Storage and International Transfers
Loaded HTML content and display preferences remain under customer control through Microsoft 365 and the PowerPoint document (Office document settings). The add-in assets are served over HTTPS from Datama-hosted endpoints required to run the viewer. When processing is required to provide the service, Datama applies appropriate safeguards and limits retention to what is necessary for service operation and support.

## 2.4. Sharing of Information
Datama does not sell, lease, or broker personal data. Data is shared only with subprocessors required to operate the service, under contractual confidentiality and security obligations.

## 2.5. Cookies and Tracking Technologies
The PowerPoint Add-in may use strictly necessary technical storage mechanisms (for example, Office document settings, local/session storage, or equivalent) to maintain loaded HTML content, user settings, and session continuity. No advertising trackers are used.

## 2.6. Third-party Access
Third-party access is restricted to authorized service providers strictly required for hosting, monitoring, and support, with least-privilege access controls.

## 2.7. Data Security
Datama follows Microsoft Office Add-in security principles:
- HTTPS/TLS is used for add-in endpoints and network communications.
- The add-in runs in a browser-based runtime sandbox (WebView) isolated from the host Office process.
- Generic HTML content is displayed in a sandboxed iframe.
- Access to presentation features is constrained by Office add-in permissions and manifest declarations (including `ReadDocument`).
- Sensitive secrets (such as passwords or long-lived credentials) must not be stored in Office settings objects or embedded in uploaded HTML when avoidable.

## 2.8. Notification in Case of Data Breach
In the event of a confirmed security incident affecting customer data, Datama will notify impacted customers without undue delay, according to contractual and legal obligations.

## 2.9. Links to Other Sites
This documentation may include links to external resources (for example, Microsoft documentation). Datama is not responsible for third-party privacy practices. Users who load custom HTML are responsible for the content they import into the add-in.

## 2.10. Unsubscribing
Users can stop using the add-in at any time by removing it from PowerPoint or through Microsoft 365 admin controls. Removing the add-in or deleting the related content from the presentation stops further use of stored HTML in that slide context.

## 2.11. Changes to This Privacy Policy
This policy may be updated to reflect product, legal, or security changes. The latest version is published on Datama documentation pages.

## 2.12. Children
HTML viewer by Datama for PowerPoint is intended for professional/business use and is not designed for children under 13.
