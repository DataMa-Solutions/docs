> Using Datama Solutions in PowerPoint is a great way to keep your analyses interactive inside presentations—without freezing charts as static images.

<br/>

Datama for PowerPoint is available as a free Office add-in (**HTML viewer by Datama**).
It complements the existing Datama extensions (Compare, Detect, Assess and Explore): export your analysis as HTML from those hosts, then bring it into a slide.

The visualization stays interactive in edit mode and in presentation mode, with the same reactivity as in the source extension—except that the dataset is fixed at the time of the HTML export.

Beyond Datama exports, you can also load **any custom HTML** file (or paste HTML via **Custom code**). The add-in displays it in a sandboxed viewer on your slide—useful for interactive widgets, embedded charts, or any self-contained HTML content you want to present live.

PowerPoint is a good fit when you want to:

- present Datama insights live without switching back to a BI tool
- keep charts interactive during a slideshow (zoom, drill-down, filters)
- reuse analyses already built in Looker Studio, Tableau, Qlik, Excel, or Google Sheets™
